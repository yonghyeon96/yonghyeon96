## Selected Projects

### Robot Localization and Navigation Labs
Implemented robotics algorithms for mobile robot state estimation and navigation, including motion models, Extended Kalman Filter, Particle Filter, and sensor-based localization experiments. These projects helped me understand uncertainty, sensor noise, and the role of probabilistic estimation in robotic autonomy.

### Production-Oriented ML System: SpotyBoys
Worked on an MLOps-based music recommendation system involving data versioning, model training/evaluation, online serving, and cloud-based infrastructure. The project strengthened my experience in building reproducible ML pipelines and deployable systems.

### Real-Time Embedded Systems
Studied and implemented real-time system concepts relevant to robotic control loops, including timing constraints, latency, and embedded system design.

### Networked Systems Labs
Completed hands-on networking labs involving Linux testbeds, routing, NAT, VPNs, packet capture, and protocol analysis. These experiences support my interest in distributed and networked robotic systems.
